# 🎵 DAW Collaboration Studio

A community collaboration Digital Audio Workstation where producers can upload beats and vocalists can record their versions, with community voting to highlight the best collaborations.

## Features

- 🎧 **Beat Upload**: Producers can upload beats with metadata (genre, BPM, description)
- 🎤 **Vocal Recording**: Vocalists can record and upload their version of any beat
- ⭐ **Voting System**: Community votes on the best vocal versions (1-5 stars)
- 🏆 **Leaderboards**: Top producers and vocalists ranked by points
- 🔥 **Sorting**: View newest or most popular songs
- 👤 **Authentication**: User registration and login system

## Tech Stack

- **Backend**: Node.js, Express
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Storage**: Local file system (uploads), JSON files (data)
- **Authentication**: JWT, bcrypt
